# EntropyGeneration

Evaluation of local volumetric entropy generation mechanisms and global second-law entropy balance.

## Contents
- `entropy_balance.m`: Domain entropy balance comparing net boundary fluxes with integrated volume generation.
- `entropy_generation_chemical_reaction.m`: Entropy generation from finite-rate chemical reactions (SMR, WGS).
- `entropy_generation_flow_viscosity.m`: Entropy generation from viscous Darcy/Brinkman dissipation in porous media.
- `entropy_generation_heat_transfer.m`: Entropy generation from Fourier heat conduction.
- `entropy_generation_species_diffusion.m`: Entropy generation from multicomponent mass diffusion.
