# BoundaryTypes

Specific boundary condition classes implementing the `IBoundaryType` interface.

## Contents
- `IBoundaryType.m`: Abstract base class for boundary condition patches.
- `FixedValueBoundary.m`: Uniform Dirichlet boundary condition.
- `FixedNormalDerivativeBoundary.m`: Uniform Neumann boundary condition.
- `NonUniformFixedValueBoundary.m`: Spatially varying Dirichlet boundary condition.
- `NonUniformConvectiveBoundary.m`: Spatially varying Robin convective boundary condition.
