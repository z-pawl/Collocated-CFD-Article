# Solvers

Linear algebra solvers and matrix relaxation routines for structured collocated finite volume systems.

## Contents
- `tdma.m`: Tridiagonal Matrix Algorithm (Thomas algorithm) for 1D tridiagonal systems.
- `solve.m`: Line-by-line alternating direction TDMA solver for 2D structured grids.
- `implicit_relaxation.m`: Implicit under-relaxation (Patankar diagonal modification).
